# 강남별관 종합일지 입력형 HTML 설계

## 목표

`2026년 10월 강남별관 종합일지.xlsx`의 날짜별 운영 입력 흐름을 브라우저에서 수행할 수 있는 오프라인 HTML 인터페이스를 만든다. 원본 엑셀은 수정하지 않는다.

## 범위

- 날짜별 기록: 날씨, 최저/최고기온, 본관·신관 전기 계량기 금일/전일 지침, 냉난방·보일러 운전시간/사용량, 수도 검침, 근무인원, 특이사항
- 자동 계산: 계량기 사용량, 본관/신관 유효·무효 사용량 합계, 누계, 수도 사용량
- 본관·신관 시설순찰 체크리스트와 메모
- 브라우저 `localStorage` 자동 저장, JSON 백업/복원, CSV 내보내기

## 비범위

- 다중 사용자 서버, 인증, 데이터베이스
- 엑셀 파일 직접 수정 또는 양방향 동기화
- 엑셀의 인쇄용 병합 셀 레이아웃을 픽셀 단위로 재현

## 운영 규칙

- 기본 월은 2026년 10월이며 날짜는 1~31일을 선택한다.
- 금일·전일 지침이 모두 숫자이면 사용량을 계산하고, 하나라도 비어 있으면 `입력 대기`로 표시한다.
- 누계는 사용량이 계산된 날짜만 누적한다.
- 저장은 날짜 변경, 입력 변경, 명시적 저장 버튼에서 수행한다.
- 원본 파일은 읽기만 하며 산출물은 별도 HTML/JS 파일이다.

## 화면

- 상단: 월/일자 선택, 저장 상태, 저장·초기화·백업·복원·CSV 버튼
- 카드: 날씨·기온, 전력 계량기, 냉난방/보일러, 수도 검침, 인원·특이사항
- 하단: 자동 계산 요약과 시설순찰 체크리스트

## 검증

- 순수 계산 함수의 사용량·합계·누계 및 빈 입력 처리를 Node 테스트로 검증한다.
- 브라우저에서 날짜 전환, 입력 저장/복원, JSON 백업/복원, CSV 생성, 계산 결과 갱신을 확인한다.
